# Space Shooter Game 🚀

یک بازی آنلاین ساده و سرگرم‌کننده!

## چطور بازی کنید:

1. دکمه **Start Game** رو کلیک کنید
2. از کلیدهای **← →** برای حرکت استفاده کنید
3. **Space** رو برای شلیک فشار دهید
4. دشمن‌ها رو نابود کنید و امتیاز جمع کنید!

## قوانین:

- هر دشمن شکست خورده = **10 امتیاز**
- شما **3 جان** دارید
- اگر دشمن به پایین برسد، یک جان می‌بازید
- وقتی تمام جان‌ها تموم شوند، بازی تمام می‌شود

## فناوری‌ها:

- HTML5 Canvas
- Vanilla JavaScript
- Pure CSS

**برای شروع:** فایل `index.html` رو در مرورگر باز کنید!
